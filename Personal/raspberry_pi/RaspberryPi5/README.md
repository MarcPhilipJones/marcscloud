# Raspberry Pi 5 Project

Direct connection to Raspberry Pi 5 at `192.168.0.111`.

## Connection Details

- **Host:** 192.168.0.111
- **User:** admin
- **Port:** 22

## SSH Connection

```bash
ssh admin@192.168.0.111
```

## Usage

Use the VS Code Remote-SSH extension to connect and develop directly on the Pi.
