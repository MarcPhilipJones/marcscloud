# McClaren PowerApp

A Power App designed specifically for McClaren business requirements.

## Project Structure

```
mcclaren-powerapp/
├── README.md           # This file
├── docs/               # Design documentation
├── assets/             # Images, icons, and media
├── src/                # Canvas app source files
│   └── screens/        # Screen definitions
├── components/         # Reusable components
├── connectors/         # Custom connector definitions
└── deployment/         # Environment-specific configs
```

## Getting Started

### Prerequisites

- Power Apps maker license
- Access to McClaren Dataverse environment
- VS Code with Power Platform Tools extension

### Development Workflow

1. Design screens in the `docs/` folder
2. Build in Power Apps Studio
3. Export app source using Power Platform CLI
4. Store exported source in `src/`
